🛡️ Kas ir pfSense?

pfSense ir bezmaksas, atvērtā pirmkoda tīkla ugunsmūris un maršrutētājs, kas balstīts uz FreeBSD operētājsistēmu. Projektā izmanto m0n0wall projekta principus, taču piedāvā daudz plašākas iespējas un lietotājam draudzīgu tīmekļa saskarni.

pfSense tiek izmantots gan mājas tīklos, gan korporatīvajā vidē. Tas spēj aizstāt dārgus komerciālus ugunsmūrus (piemēram, Cisco ASA, Fortinet) bez papildu licencēšanas izmaksām.

💡 Zināms fakts: pfSense Community Edition (CE) ir pilnīgi bezmaksas. Netgate piedāvā arī komerciālu versiju – pfSense Plus – ar papildu atbalstu.
📅

Dibināts 2004. gadā

Projekts sākās kā m0n0wall forks. Pirmā stabila versija iznāca 2006. gadā.

💻

Balstīts uz FreeBSD

Stabila un droša Unix sistēma nodrošina uzticamu darbību pat ilgstošā nepārtrauktā lietošanā.

🌐

Tīmekļa saskarne

Visu konfigurāciju var veikt caur pārlūku – nav nepieciešams strādāt ar komandrindas konsoli.

🔌

Paplašinājumi (pakotnes)

Pieejamas simtiem papildu pakotnes: pfBlockerNG, Suricata, HAProxy un citas.

⚙️ Galvenās funkcijas

🔥 Ugunsmūris (Firewall)

pfSense izmanto pf (Packet Filter) kā savu ugunsmūra dzinēju, kas nāk no OpenBSD projekta. Ar to var:

  • Izveidot noteikumus pēc IP adreses, porta, protokola un citu kritēriju
  • Atļaut vai bloķēt trafiku starp tīkla zonām (WAN ↔ LAN ↔ DMZ)
  • Izmantot stateful savienojumu izsekošanu
  • Konfigurēt NAT (Network Address Translation) un Port Forwarding
  • Izmantot GeoIP bloķēšanu ar pfBlockerNG

🔒 VPN (Virtual Private Network)

pfSense atbalsta vairākus VPN protokolus:

  • OpenVPN – visvieglāk uzstādāms, labi saderīgs ar mobilajām ierīcēm
  • IPsec / IKEv2 – standarts starp-tīklu (site-to-site) tunelēšanai
  • WireGuard – moderns, ātrs, maz resursu patērē
🟢 Skolēniem: VPN ļauj droši pieslēgties skolas tīklam no mājām!

📡 DHCP & DNS

DHCP serveris automātiski piešķir IP adreses tīkla ierīcēm. pfSense ļauj:

  • Konfigurēt adresu diapazonus (pool)
  • Piešķirt fiksētas adreses pēc MAC adreses
  • Iestatīt custom DNS un Gateway

DNS Resolver (Unbound) ātrina DNS uzmeklēšanu un ļauj bloķēt nevēlamas domēnu adreses.

📊 QoS & Traffic Shaping

Joslas platuma pārvaldība nodrošina, ka svarīgā trafika (VoIP, videokonferences) saņem prioritāti pār mazāk svarīgo (torenti, YouTube).

# Prioritāšu kārta (HFSC queue piemērs)
VoIP      → Priority 7  (augstākā)
HTTP/S    → Priority 5
Downloads → Priority 2
P2P       → Priority 1  (zemākā)

🚨 IDS/IPS – Ielaušanās noteikšana

Ar pakotni Suricata vai Snort pfSense kļūst par pilnvērtīgu IDS/IPS sistēmu, kas:

  • Analizē tīkla trafiku reāllaikā
  • Automātiski bloķē aizdomīgas IP adreses
  • Pielieto regulāri atjaunotas noteikumu kopas (Emerging Threats, VRT)

🗺️ Tīkla arhitektūra

Tipiskā pfSense izvietojuma shēma: pfSense atrodas starp internetu (WAN) un lokālo tīklu (LAN). Var pievienot arī DMZ zonu serveriem.

📌 DMZ (Demilitarizētā zona) – atsevišķa tīkla zona publiskiem serveriem (web, e-pasts). Tā aizsargā LAN, ja DMZ serveris tiek uzlauzts.

💿 Instalācijas process

pfSense var instalēt uz fiziska datora vai virtuālas mašīnas (VirtualBox, VMware, Proxmox). Minimālās prasības:

⚡ Minimālās prasības

  • CPU: 64-bit, 1 GHz
  • RAM: 1 GB (ieteicams 2 GB+)
  • Disk: 8 GB
  • Tīkla karte: 2 × NIC (WAN + LAN)

🚀 Ieteicamās prasības

  • CPU: 64-bit multi-core
  • RAM: 4 GB+
  • Disk: SSD 32 GB+
  • Tīkla karte: Intel NIC
1

Lejupielādēt ISO attēlu

Dodieties uz pfsense.org → Downloads → izvēlieties AMD64 arhitektūru un DVD Image (ISO).

2

Ierakstīt USB disku vai palaist VM

Fiziskai instalācijai izmantojiet Rufus vai balenaEtcher. Virtuālai – izveidojiet VM ar 2 tīkla kartēm.

3

Boot un installer

Palaidiet no instalācijas medija. Izvēlieties "Install pfSense" → Accept → particionēšana → atlasiet disku → reboot.

4

Sākotnējā konfigurācija konsolē

Pēc pirmās palaišanas konsole lūdz piešķirt interfeisus (WAN = em0, LAN = em1) un WAN IP.

Enter the WAN interface name: em0
Enter the LAN interface name: em1
# DHCP vai statiskā IP adrese WAN interfeisam

Pieslēgties tīmekļa saskarnei

No LAN tīkla atvēriet pārlūku: https://192.168.1.1

🔧 Pamata konfigurācija

Noteikumus konfigurē sadaļā Firewall → Rules. Katra noteikuma rinda nosaka: darbību (Pass/Block/Reject), protokolu, avotu un galamērķi.

⚠️ Noteikumi tiek pārbaudīti no augšas uz leju. Pirmais atbilstošais noteikums tiek pielietots!

Piemērs: atļauj LAN trafiku uz internetu, bet bloķē Facebook:

Action: Block  | Proto: TCP | Src: LAN | Dst: 157.240.0.0/16
Action: Pass   | Proto: *   | Src: LAN | Dst: *

NAT (Network Address Translation) ļauj ierīcēm ar privātām IP adresēm piekļūt internetam izmantojot vienu publisko IP.

Port Forwarding novirza ienākošos savienojumus uz iekšējo serveri:

WAN:80  → 192.168.1.50:80   # Web serveris
WAN:443 → 192.168.1.50:443  # HTTPS
WAN:22  → 192.168.1.10:22   # SSH

pfSense piedāvā reāllaika monitoringu:

  • Status → Dashboard – sistēmas pārskats, CPU, RAM, trafiks
  • Status → Traffic Graph – reāllaika joslas platuma grafiks
  • Status → System Logs – ugunsmūra, DHCP, VPN žurnāli
  • Diagnostics → Packet Capture – trafika analīze (kā Wireshark)
🟢 Padoms: Regulāri pārbaudiet System Logs, lai atklātu aizdomīgus pieslēgšanās mēģinājumus.

Sadaļā System → Package Manager var instalēt papildu funkcionalitāti:

📦 pfBlockerNG – reklāmu un ļaunatūras bloķēšana DNS līmenī
📦 Suricata – ielaušanās noteikšanas sistēma (IDS/IPS)
📦 HAProxy – load balancer un reverse proxy
📦 ntopng – detalizēta tīkla trafika analīze
